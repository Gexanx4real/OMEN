OMEN — Beatmaps
=================

Aus Platz- und Vertriebsgründen enthält dieser Release-Ordner keine Beatmap-Dateien (Audio/Video).

- Maps vom Entwickler-PC: Inhalt von assets\maps aus dem Quellprojekt hierher kopieren.
- Oder im Spiel: Beatmaps suchen/importieren (Menü → Beatmaps) oder Editor nutzen.

Vollständiges Paket mit lokalen Maps: Im Quellprojekt build_release.bat; danach optional Ordner manuell ergänzen.
